# iMAG3 Studio and XXX!NK
`Studio/android/` is the Android app, `Studio/dashboard/` is the dashboard shared by Android and the browser, and `Studio/web/` is the XXX!NK PHP site. Change the dashboard here once and assemble both deliverables from the same commit.

Run `bash Studio/assemble.sh` to create `studio-build/android-source/` and `studio-build/web/`. Pass a new directory path as an argument for another build. The script checks the historical Next archive's checksum and extracts only the bundled brand media, OCR dependencies, NanoHTTPD and the raster color profile. The tracked Studio directories supply the application code. See [Android build and signing](ANDROID.md) and [web deployment](web/IONOS-SETUP.md). Generated output belongs outside source control.

The earlier native scaffold and Phone Host Next build are available in Git history. Studio includes Phone Host Next's host, scanner and workdesk, plus the authoring and Wide Net work. Remotive is available as a source link in Wide Net. Its earlier polling implementation was retired with the scaffold.

## Wide Net

1. **Discovery.** Open **Wide Net → Sweep live sources**. The shared dashboard reads UK Find a Tender (up to two pages), Seattle/King County 4Culture, Artquest, ASEF culture360, African Culture Fund and Freedom With Writing. Android also uses its existing Grants.gov, EU TED and On the Move scout. The browser calls Grants.gov directly. Source health shows available responses, empty results and failures. Use the region and language filters to narrow your shortlist. Multilingual search and the directories link to additional public sources.
2. **Evidence.** Open a brief and record the organizer’s posting, status and deadline, eligibility, compensation and an official application route. Check each field you verified. Undisclosed compensation can be recorded explicitly. Confirm applicant counts independently with a published evidence link. Set the recheck interval in **Capacity and rechecks**. The optional daily sweep runs while Wide Net is open. Changed feed fields invalidate affected checks, while expiring or unavailable evidence remains visible for follow-up.
3. **Portfolio.** In **Album intake**, use **Tag for Wide Net** beside an imported image. Enter its subjects, styles, medium and rights clearance for pitches. Wide Net ranks opted-in, currently cleared work, shows matched terms and brief excerpts, and lets you pin or exclude assets for a specific brief. A retained original or edited copy can open in Authoring Studio.
4. **Production.** Set weekly hours, existing commitments and a minimum rate. Each brief supports separate application and production dates, a medium-specific estimate, dependencies, direct costs and a fee in USD. Estimates allow a 30% buffer, subtract overlapping reservations and suggest a small proof. The fee field is a production planning input; posted grant amounts stay separate.
5. **Speculative products.** **Refresh ranked ideas** proposes deliverables from verified briefs and retrieves or updates Wikimedia topic-view evidence. You can also record dated search, click or purchase observations with a source and measurement window. Topic views are an attention signal. Confirm the product’s fit and the verified buyer route before adding it to Workdesk. A separate confirmation is required for a direct checkout link.

The hosted dashboard relays a fixed set of public sources through `wide-feed.php`; the Android dashboard uses the same catalog via its local WebView. The PHP host needs outbound HTTPS through cURL or URL streams for these sources. Static-only hosts rely on the provider’s cross-origin support. All qualification, drafting and outreach remain under operator control. The evidence schedule pauses when the screen is closed.
